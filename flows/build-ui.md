# Build UI

Use this flow for a new screen, a redesign, or any change where the look matters.

## The steps

1. **Set the point of view.** Run `grill-me` on the design. It asks who the users are, what they care about and what the product wants to be to them, and writes the answer to `docs/design.md`. Skip this step when the repo already has that file.
2. **Try it cheap.** Run `prototype` to build a throwaway version of the screen or the state model. React to something real before you build the real thing.
3. **Build it with taste.** Run `ui-taste` to design or review the UI, so that it does not look machine-made. Then run `implement` to build it.
4. **Show it.** Run `before-after` to capture the change as labelled screenshots or a short video.
5. **Tweak it.** Walk the flows yourself and list the tweaks. One agent makes them all in one round.
