# Example taste entry

This is an illustration of the format, not a real site. Real entries come from a teardown of a
real reference and live in the project's `docs/taste/` folder.

URL       https://example.com/ (fictional)
Mood      calm, light, precise, dense
Fits      an analytics or admin tool that people use every day
Stack     Next.js, Tailwind 4 `@theme`, Motion
Fonts     one sans family at 400, 500 and 600, self-hosted, system fallback with matched metrics
Palette   text #1A1A1A, page #FAFAF9, surface #FFFFFF, line text at 10%, accent #2F6BFF
Type      page title 24/1.25 at -0.01em, section 16/1.3 at 600, body 14/1.5, meta 12/1.4
Layout    content 1200, gutters 24, section gap 48, radius 6px controls and 10px cards
Motion    hover 120ms, dialogs scale from 0.98 over 180ms, no scroll reveals
Sections  top bar, filter row, stat strip, main table, side panel for the selected row

## Signature moves

1. Stats sit in one strip split by hairlines, with tabular numbers and the unit in the secondary step.
2. The selected table row opens a side panel instead of a new page, so the list keeps its scroll.
3. The accent appears only on the primary action, the focus ring and the selected row.
